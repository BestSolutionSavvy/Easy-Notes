\section{Requisiti non funzionali}
\begin{itemize}
    \item \textbf{Usabilità}\par
    Il sistema deve fornire un'interfaccia grafica intuitiva e semplice da utilizzare, pensata principalmente per studenti universitari.
    \item \textbf{Prestazioni}\par
    Il caricamento delle slide e degli appunti associati deve avvenire in tempi ridotti, anche in presenza di file di grandi dimensioni. Il sistema deve supportare più utenti concorrenti senza degradare sensibilmente le prestazioni.
    \item \textbf{Compatibilità}\par
    La Web App deve essere accessibile dai principali browser moderni. Il sistema deve essere utilizzabile su diversi dispositivi (desktop, tablet, laptop) senza perdita di funzionalità.
\end{itemize}
