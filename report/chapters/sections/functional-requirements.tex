\section{Requisiti funzionali}

\subsection{Requisiti Utente}
\begin{itemize}
    \item L'utente deve poter creare un account come studente o professore.
    \item L'utente deve poter effettuare il login e logout.
    \item L'utente deve poter modificare o cancellare il proprio account.
    \item Un professore deve poter creare, modificare e cancellare classi.
    \item Uno studente deve poter iscriversi e disiscriversi dalle classi.
    \item Uno studente deve poter attivare le notifiche per la pubblicazione di nuove slide nelle classi a cui è iscritto.
    \item Uno studente deve poter scaricare le slide caricate nelle classi a cui è iscritto.
    \item Uno studente deve poter caricare le proprie slides in un archivio personale dell'applicazione.
    \item Un professore deve poter creare e cancellare slide associate alle proprie classi.
    \item Uno studente deve poter prendere appunti associati alle slide scaricate.
    \item Uno studente deve poter prendere appunti generici non associati a nessuna slide.
    \item Uno studente deve poter evidenziare parti delle slide scaricate.
    \item Uno studente deve poter cercare parole chiave all'interno delle proprie note e slide.
    \item Uno studente deve poter riassumere in automatico le proprie note.
\end{itemize}

\subsection{Requisiti di sistema}
\begin{itemize}
    \item L'applicazione deve salvare per ogni account i dati relativi alle note, slide e classi.
    \item L'applicazione deve inviare notifiche agli utenti quando nuove slide vengono caricate nelle classi a cui sono iscritti.
    \item L'applicazione deve mandare notifiche agli utenti quando la generazione del riassunto delle note è completata.
\end{itemize}
